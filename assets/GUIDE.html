DSH Figma MCP 用户手册User Guide

本手册内容涵盖连接授权流程、对话中的使用方式、内置工作流的用途，以及常见问题的排查方法。 This guide covers the authorization flow, usage in conversation, built-in workflows, and troubleshooting.

1. 快速开始1. Quick Start

前提条件Prerequisites

  • 已安装 DSH（安装方法见 DSH installed (see READMEREADME）；);
  • 拥有 Figma 账号，且当前设备的浏览器可正常访问 figma.com；A Figma account, and a browser on this device that can access figma.com;
  • 对目标 Figma 文件具备相应权限：读取内容需查看权限，写操作需编辑权限。Proper permissions on the target Figma file: view access to read content, edit access to write.

步骤Steps

  1. 安装插件后重启 DSH。Restart DSH after installing the plugin.
  2. 打开「设置 → DSH Figma MCP」，点击「连接 Figma」，在弹出的浏览器页面中登录并同意授权。Open "Settings → DSH Figma MCP", click "Connect Figma", and approve the OAuth flow in the popup browser page.
  3. 浏览器提示授权成功后返回 DSH，卡片将在数秒内自动切换为「已连接」，无需手动刷新。After the browser shows success, return to DSH. The card auto-switches to "Connected" within seconds — no manual refresh needed.

连接成功后，可在对话中通过以下两种方式使用：Once connected, you can use the plugin in two ways:

  • 自然语言Natural language：在对话框中粘贴 Figma 链接并描述任务意图；: paste a Figma link in the chat box and describe your intent.
  • 工作流指令Workflow command：输入 : type /dsh-figma-mcp <command> 开启工作流。to start a workflow.

2. 设置卡片2. Settings Card

卡片位于「设置 → DSH Figma MCP」，分「连接」和「Skill」。Located at "Settings → DSH Figma MCP", the card has "Connection" and "Skill" sections.

2.3 Skill 开关2.3 Skill Toggle

  • 默认开启：插件将 On by default: the plugin injects dsh-figma-mcp-skill 注入 Agent 技能列表，Agent 据此选择应调用的 Figma 工具和解析链接。into the Agent's skill list so the Agent can pick proper Figma tools and parse links.
  • 关闭后：连接功能不受影响，但 Agent 不再获得上述引导，建议保持开启。Off: connection still works, but the Agent no longer receives the guidance — keep it on.

3. 自然语言3. Natural Language

连接后在对话中粘贴 Figma 链接并说明意图即可，例如：After connecting, paste a Figma link in chat and describe your intent. For example:

  • 「帮我看看这个设计稿里有什么："Take a look at this design: https://www.figma.com/design/<file-id>/...?node-id=1-2」"
  • 「把上面这个页面转成 React 代码」"Convert the page above into React code."
  • 「从这个文件里抽出所有按钮和标题文案，做成中英文 i18n 对照表」"Extract all button and heading copy from this file into a CN/EN i18n table."

4. 工作流指令4. Workflow Commands

4.1 语法4.1 Syntax

/dsh-figma-mcp <command> [extra notes]
  • <command> 为下表中的 17 个之一。is one of the 17 listed below.
  • [extra notes] 为可选项，提供后将作为初始说明自动填充。is optional and auto-fills the initial intent.

示例：Examples:

/dsh-figma-mcp look https://www.figma.com/design/xxxx/Shop?node-id=1-2
/dsh-figma-mcp edit 把主按钮改成品牌蓝，复用已有颜色变量
/dsh-figma-mcp asset 保存到 ./figma-assets，倍率用节点自带设置/dsh-figma-mcp look https://www.figma.com/design/xxxx/Shop?node-id=1-2
/dsh-figma-mcp edit change the primary button to brand blue, reuse existing color variables
/dsh-figma-mcp asset save to ./figma-assets, use node's built-in export settings

6. 授权、数据与安全6. Authorization, Data & Security

  • OAuth 由 Figma 官方页面在浏览器中完成，无需手动粘贴令牌，超时后需重新点击「连接 Figma」。OAuth is performed by Figma's official page in the browser — no manual token paste. On timeout, click "Connect Figma" again.
  • 令牌与刷新凭据保存在本机 DSH 配置目录中：Tokens and refresh credentials are stored locally in the DSH config dir:
    • 连接数据：Connection data: <DSH_HOME>/cordis.patch.yml（默认 (default ~/.dsh/，可通过环境变量 , overridable via DSH_HOME 覆盖）；);
    • 插件配置（Skill 开关）：Plugin config (Skill toggle): <DSH_HOME>/figma-mcp/config.json。.
  • 令牌不会出现在对话内容、生成的文件或 README 中。Tokens never appear in chat, generated files, or the README.

7. 常见问题7. FAQ

点击「连接 Figma」后浏览器未弹出？Browser doesn't pop up after clicking "Connect Figma"?
检查浏览器是否被弹窗拦截器拦截；允许弹窗后重新点击。 Check whether the popup was blocked by the browser; allow popups and try again.

浏览器已提示授权成功，卡片状态未更新？Browser shows success but the card status doesn't update?
卡片每 1.5 秒自动查询一次状态，通常数秒内完成切换。若超过 15 秒仍为「未连接」，请确认浏览器回调页显示的是成功提示，然后重新打开设置页；若仍失败，重新发起一次连接。 The card polls every 1.5s and usually switches within seconds. If it's still "Disconnected" after 15s, confirm the callback page shows success, then reopen settings; if still failing, retry the connection.

状态长时间停留在「加载中」？Stuck on "Loading" for a long time?
说明设置页未能获取后端状态。关闭设置页后重新打开；无效则重启 DSH。 The settings page failed to fetch backend status. Close and reopen the settings; otherwise restart DSH.

「刷新授权」报错？"Refresh" errors?
通常是刷新凭据也已失效，请直接点击「重新授权」，重新完成浏览器授权流程。 Usually the refresh credential has also expired. Click "Re-authorize" and redo the browser OAuth flow.
